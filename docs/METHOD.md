# 평가 및 진단 설계

## 데이터와 대상

`Date`를 우선해 파생 날짜를 다시 계산하되, 매장·상품·날짜 키가 충돌하면 보류했습니다. 기본 분석에서는 24번 매장을 제외했습니다.

미관측·음수 타깃은 결측으로 유지하고 0으로 채우지 않았습니다. 매출이 0이라는 이유만으로 판매수량을 삭제하지 않았습니다. 상품 코드를 유지했으며 세트를 분해하거나 단품에 합산하지 않았습니다.

최초 26주에서 매주 유효한 기록이 있고 주평균 판매량이 20개 이상인 **172개 조합**을 고정했습니다. 최초 학습 기간 평균에 따른 `[20, 40)`, `[40, 80)`, `[80, ∞)` 구간은 보고용으로만 사용했습니다.

## 시점과 비교 집합

전주 판매량과 직전 4개 달력 주의 평균을 기준선으로 사용했습니다. 4주가 모두 유효할 때만 평균을 계산했습니다.

실제값과 두 기준선이 모두 있는 공통 키를 모델 실행 전에 저장했습니다. 모든 방법은 같은 키에서 비교하며, 모델 예측 누락은 별도로 보고합니다.

## 모델 사양

LightGBM의 원수량 L1 모델을 사용했습니다. 잎 수 7개와 31개를 비교하고, 학습률 0.05, 트리 수 300, seed 42를 고정했습니다. 검증 전체 WAPE로 잎 수 7개를 선택했습니다.

초기 4주 이후의 유효 타깃 행을 사용하며, 매주 직전까지의 자료로 전역 모델을 다시 학습합니다. 피처는 다음과 같습니다.

- 직전 1~4주 판매량
- 직전 4주 평균과 표준편차
- 직전 주와 그 전주의 판매량 차이
- 직전 주 가격
- 매장, 상품 코드, 유형 범주

상세 사양은 [`05_model_spec.json`](../05_model_spec.json)에 있습니다.

## 최종 판단 규칙

모델의 최종 WAPE가 전주 기준선보다 낮으면 모델을 선택하고, 같거나 높으면 전주 기준선을 유지합니다. Bias는 별도로 보고합니다.

사양과 다른 구현 오류만 수정할 수 있으며, 수정한다면 원실행과 수정 이유, 수정 전후 결과를 보존합니다. 결과를 본 뒤 사양과 점검 문턱값을 바꾸지 않습니다.

점검 대상은 공통 평가가 10주 이상이고, 같은 방향의 오차가 8주 이상이며, 누적 Bias가 ±10%를 넘는 조합입니다. 경계값인 +10%, −10%도 포함합니다. 유효 평가가 10주 미만이면 자료 부족 대상으로 분류합니다. 이 규칙은 통계적 유의성 기준이 아니며, 전체 Bias와 함께 해석합니다.

## 사후 기술 분석

주별 오차 기여도, 26개 평가 주를 모두 관측한 156개 조합의 추이, 결측의 영향 전파를 진단했습니다.

SHAP 사례는 `전주 절대오차 − 모델 절대오차`의 최댓값·최솟값으로 선정했습니다. 동률이면 날짜, 매장, 상품 코드 순으로 정렬합니다. 최종 결과를 본 뒤 정한 진단 규칙이며 모델 선정에 다시 사용하지 않았습니다.

직전 주 판매량 구간표도 사후 기술용입니다. 최초 학습 평균으로 고정한 보고용 구간과 구분합니다. SHAP은 해당 주 모델의 기준값 대비 예측 기여를 설명하며, 실제 판매 변화나 오류의 인과 원인을 증명하지 않습니다.

## 보고 시점

전주 기준선의 Bias는 최종 12주 전체에서 −2.43%, 마지막 4주에서 +5.74%였습니다. 점검 목록은 12주 기준으로 유지하고 최근 방향 변화는 별도로 보고합니다.

방법 유지 제안은 최종 평가가 끝난 뒤 내린 판단입니다. 당시 이미 그 방법을 선택해 실제 발주를 운영한 것처럼 표현하지 않습니다.
